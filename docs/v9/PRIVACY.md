# حریم خصوصی — نسخه 9.0.0

- اطلاعات موکل، پرونده، وقت رسیدگی، پروفایل، سفارش‌ها و نشانی‌های شخصی به‌صورت رمز‌شده و محلی ذخیره می‌شوند.
- برنامه حساب ابری، پرداخت آنلاین یا همگام‌سازی سراسری ندارد.
- استفاده از هوش مصنوعی اختیاری و برخط است. متن سؤال و دستور حقوقی پس از تأیید کاربر مستقیماً به ارائه‌دهنده انتخابی او (OpenRouter، Groq یا Hugging Face) ارسال می‌شود و تابع شرایط و سیاست حریم خصوصی همان سرویس است.
- کلید API شخصی کاربر در Android Keystore/مخزن رمزگذاری‌شده نگهداری می‌شود؛ در رابط وب قابل بازیابی نیست و با حذف کلید یا پاک‌کردن اطلاعات برنامه حذف می‌شود.
- برنامه اطلاعات موکل را خودکار به هوش مصنوعی ارسال نمی‌کند. کاربر مسئول حذف داده‌های هویتی، شماره پرونده، اسناد محرمانه و اسرار حرفه‌ای پیش از ارسال است.
- تماس، نقشه، ایمیل، چاپ و اشتراک‌گذاری فقط پس از اقدام روشن کاربر به برنامه خارجی واگذار می‌شود.
- اعلان فقط برای یادآوری انتخابی کاربر درخواست می‌شود. بدون مجوز اعلان، یادآوری فعال ثبت نمی‌شود.
- حذف اطلاعات، پس از عبارت تأیید و در صورت وجود قفل، احراز هویت تازه، داده‌های برنامه، هشدارها و کلید رمزنگاری را حذف می‌کند.
- Android Backup غیرفعال است. برای مواعد حیاتی باید یک روش پشتیبان مستقل و امن نیز استفاده شود.

نسخه رایگان یا سهمیه رایگان ارائه‌دهندگان هوش مصنوعی ممکن است بدون اطلاع برنامه تغییر کند. برنامه تضمینی درباره دسترس‌پذیری، محل پردازش یا نگهداری داده توسط سرویس ثالث ارائه نمی‌دهد.
